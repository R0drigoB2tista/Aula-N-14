# Aula 14 - Arquitetura de Computadores - Mod 4A

## Resumo da aula

Continuámos a aprofundar a arquitetura dos sistemas computacionais e os seus blocos principais (microprocessador, memória, dispositivos de E/S e sistemas de comunicação). Realizámos também uma tarefa prática de pesquisa para recolher informação e características detalhadas sobre cada um destes elementos.

## Comentário da aula

O trabalho de pesquisa foi muito interessante porque nos obrigou a procurar exemplos reais e especificações técnicas atuais de hardware, consolidando os conceitos aprendidos.
